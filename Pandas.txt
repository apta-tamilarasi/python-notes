import numpy as np

    'Age': [20, 21, 22, 23, 24]

TOPIC 19: Performance
1) Use vectorized operations instead of loops
2) Avoid apply() with large data
3) Use category dtype for string columns with few unique values
4) Use query() for filtering large DataFrames
5) Use chunk processing for very large files
